# Contributing

Install using the README and run `python -m unittest discover -s tests -q` in one process. Include deterministic regression cases for scoring, caps, privacy and task construction. Do not run real models during tests.

Tasks need an attributable permissive source, LICENSE-SOURCE, a source manifest and a check that fails before the fix and passes after it. Review authorship markers and state uncertainty. Keep hidden checks and gold outside the starting tree. Update THIRD_PARTY_NOTICES.md when adding third-party content.

Do not submit credentials, transcripts, machine-specific paths or session records. Use the issue tracker for reproducible problems, and SECURITY.md for security reports. Label measurements by cap profile and repeat count.
